## Overview

This repository contains the official website for **Corthorn Group**, an enterprise cybersecurity and technology consulting firm specialising in penetration testing, security architecture, GRC & compliance, managed SOC services, and AI security.

The site is built as a single-page HTML application — no frameworks, no dependencies, fully self-contained.

## Deployment

This site is deployed via **GitHub Pages**.

To deploy your own fork:

1. Fork or clone this repository
2. Ensure the main HTML file is named `index.html`
3. Go to **Settings → Pages → Branch: main → Save**
4. Your site will be live at `https://yourusername.github.io/corthorn-website`

---

## Local Development

No build tools required. Simply open `index.html` in any modern browser:

```bash
git clone https://github.com/YOURUSERNAME/corthorn-website.git
cd corthorn-website
open index.html
```
